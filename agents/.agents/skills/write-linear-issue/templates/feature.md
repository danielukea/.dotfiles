# Feature template

Only the title is required. Drop any section that carries nothing.

```md
# <short, scannable — state the task directly>

## What

<1–2 sentences: the observable change, with a clear defined outcome.>

## Why

<Optional. One line, and only if the What doesn't already imply it.>

## Where to begin

<Optional. Real paths, symbols, prior issues or PRs. Verify each exists.>

## Acceptance criteria

- [ ] <observable from outside — checkable without your notes>
- [ ] <include the negative cases: what must NOT happen>
```
