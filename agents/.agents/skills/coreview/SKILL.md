# Co-review

Build shared understanding before offering feedback. Start with the artifact's
intent and the user's concerns, then move from the overall shape into the
details that matter. Ask one unresolved question at a time, explain credible
alternatives and tradeoffs, and treat possible feedback as a hypothesis until
the user agrees.

When the discussion is complete, capture only the agreed feedback in the
format the user requested.

## Gotchas

- Do not substitute a checklist or a verdict for a conversation.
- Do not jump to implementation details before the user and artifact's goals are clear.
- Keep questions and feedback proportional to the artifact; depth should follow risk, not habit.
